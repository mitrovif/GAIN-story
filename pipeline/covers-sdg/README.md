# GAIN example cover pages

Cover thumbnails (page 1, ~520px PNG) of the GAIN example source reports we hold, named by
`example_id` (e.g. `ex045.png`). 94 examples have a rendered cover; the rest are web-page
sources with a link only.

**For another visualisation:** use `data/gain_example_links.csv`, which maps each example to:
- `source_url` — the report/landing page (119 examples)
- `cover_image` — relative path (`covers/exNNN.png`) where a cover exists (94)
- `cover_url` — the full public URL, e.g. `https://mitrovif.github.io/gain_sdg_workstream/covers/ex045.png`

The `cover_url` values are usable directly as image URLs in Flourish, Tableau, a web gallery, etc.
(they resolve once the repo is pushed and GitHub Pages has rebuilt).
